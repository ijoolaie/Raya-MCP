سرورهای MCP متصل‌شونده

فهرست از فایل تنظیمات محلی raya-admin-panel/mcp-endpoints.json خوانده می‌شود. برای امنیت، دستور اجرا و مقدار کلیدها از پنل دریافت یا نمایش داده نمی‌شوند؛ فقط شناسهٔ متغیرهای محیطی در فایل تنظیمات ثبت می‌شود.

برای دریافت فهرست، به‌روزرسانی را بزن.

ابزارهای سرور انتخاب‌شده


  

  

   
مسیرهای مجاز (Workspace Allowlist)
فقط پوشه‌هایی که اینجا ثبت می‌کنی برای ابزارهای فایل Raya قابل دسترسی خواهند بود. مسیر اصلی Raya قفل است و حذف نمی‌شود. افزودن یا حذف مسیر تا زمان ذخیره فقط پیش‌نویس است.

  

  

   
تنظیمات حیاتی
تغییر محدودیت‌ها و PowerShell پس از ذخیره، با راه‌اندازی مجدد تونل اعمال می‌شود. کلید API و اطلاعات محرمانه در فایل‌های پنل ذخیره نمی‌شوند.
