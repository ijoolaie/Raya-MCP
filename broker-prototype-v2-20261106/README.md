
- Pipe I/O resource-finalizer primitive (2026-11-08): added a terminal-only finalizer for the duplicated issuing pipe and completion event. Successful closes are tracked individually; a partial/failed close enters sticky CLOSE_UNCERTAIN, retains the failed handle value, forbids retry/release, and requires the integrating lifecycle to record HANDLE_CLOSE and refuse clean shutdown. Memory release is gated on both handles closing successfully. MSVC x64 /W4 /WX: 30 assertions/run x25, all passed (750 assertions). This is isolated and uses synthetic handles; it is not wired into the worker or pipe-io-v2.c, and it does not free OVERLAPPED/buffer/record. See PIPE-IO-RESOURCE-FINALIZER-20261108.md.
